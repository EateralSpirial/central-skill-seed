# self-evolving-project-bootstrap

## Purpose

`self-evolving-project-bootstrap` is the full skill generated by `central-skill-seed`.

It bootstraps project-level agent context and installs the project-level skill `project-context-evolution`.

It must not depend on `central-skill-seed` after generation.

## Use when

- a project has no `AGENTS.md`
- a project has no `.agent/` context
- the user asks to initialize project-level agent context
- the user asks to adopt, refresh, reconstruct, or audit project context
- existing agent instructions are stale, scattered, or contradictory

## Target project output

Create or update:

```text
AGENTS.md
.agent/project/SYSTEM_PURPOSE.md
.agent/project/CONTEXT_MAP.md
.agent/project/WORKFLOW.md
.agent/project/ITERATION_RULES.md
.agent/skills/project-context-evolution/SKILL.md
.agent/experience/LESSONS.md
.agent/experience/FAILURE_PATTERNS.md
.agent/experience/USER_CORRECTIONS.md
.agent/iteration/ITERATION_LOG.md
.agent/iteration/CHANGE_PROPOSALS.md
.agent/iteration/REVIEW_POLICY.md
.agent/evals/REGRESSION_CASES.md
.agent/evals/EVAL_POLICY.md
```

## Bootstrap procedure

1. Inspect project shape, commands, tests, docs, and existing instructions.
2. Preserve valid local rules.
3. Resolve or quarantine contradictions.
4. Generate concise `AGENTS.md`.
5. Generate detailed `.agent/` context.
6. Install `project-context-evolution`.
7. Create experience, iteration, review, and eval files.
8. Register the managed project in this full skill's `PROJECT_REFERENCES.md`.
9. Report created files, unresolved gaps, and next actions.

## Independence rule

After bootstrap, future agents must be able to maintain the project through its own files, especially:

```text
AGENTS.md
.agent/skills/project-context-evolution/SKILL.md
.agent/project/ITERATION_RULES.md
.agent/experience/
.agent/evals/
```

## Risk policy

Low-risk changes may be applied directly.

Medium-risk changes require a written proposal.

High-risk changes require explicit user approval.

## Prohibited behavior

Do not:

- make projects depend on this full skill after bootstrap
- overwrite useful project-specific context without preserving it
- store secrets or sensitive private data
- allow autonomous high-risk rewrites
- treat emotion as objective fact
- copy external repositories wholesale
