# Self-Evolving Project Bootstrap

## Identity

This is the full skill generated by `central-skill-seed`.

It is independent from the seed after generation.

Its job is to initialize, adopt, refresh, reconstruct, and audit project-level agent context environments.

## Activation

Use this skill when:

- a target project has no `AGENTS.md`
- a target project has no `.agent/` context
- the user asks to initialize project-level agent context
- the user asks to adopt or take over a project
- the user asks to refresh or reconstruct stale agent context
- the user asks to audit whether project context can self-iterate

## Target Project Output

Create or update:

```text
AGENTS.md
.agent/project/SYSTEM_PURPOSE.md
.agent/project/CONTEXT_MAP.md
.agent/project/WORKFLOW.md
.agent/project/ITERATION_RULES.md
.agent/skills/project-context-evolution/SKILL.md
.agent/experience/LESSONS.md
.agent/experience/FAILURE_PATTERNS.md
.agent/experience/USER_CORRECTIONS.md
.agent/iteration/ITERATION_LOG.md
.agent/iteration/CHANGE_PROPOSALS.md
.agent/iteration/REVIEW_POLICY.md
.agent/evals/REGRESSION_CASES.md
.agent/evals/EVAL_POLICY.md
```

## Independence Rule

Every initialized project must be able to continue project-context iteration without this full central skill and without the seed.

## Procedure

1. Inspect project shape.
2. Detect language, framework, package manager, commands, and tests.
3. Preserve valid existing rules.
4. Resolve or quarantine contradictions.
5. Generate concise `AGENTS.md`.
6. Generate detailed `.agent/` context.
7. Generate project-level context evolution skill.
8. Generate experience, review, and eval files.
9. Register the project in this full skill's `PROJECT_REFERENCES.md`.
10. Report created and updated files.

## Risk Policy

Low-risk changes may be applied directly.

Medium-risk changes require a written proposal.

High-risk changes require explicit user approval.

## Prohibited Behavior

Do not:

- make target projects depend on this full skill after initialization
- overwrite useful project-specific context without preserving it
- store secrets or sensitive private data
- allow autonomous high-risk rewrites
- treat user emotion as objective fact
- copy external repositories wholesale
