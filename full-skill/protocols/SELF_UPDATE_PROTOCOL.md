# Self Update Protocol

## Purpose

Update the full skill from managed project evidence and approved references.

## Procedure

1. Read full skill core files.
2. Read managed project registry.
3. Inspect managed project context files.
4. Extract reusable lessons.
5. Update protocols or templates minimally.
6. Preserve project independence.
7. Record update history.

## Risk Boundary

High-risk changes require explicit user approval.
